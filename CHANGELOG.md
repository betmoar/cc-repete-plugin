# Changelog

All notable changes to cc-repete are recorded here. Versions follow [semver](https://semver.org/); `.claude-plugin/plugin.json` is the single source of truth. A release is cut by pushing a `v<x.y.z>` tag — the release workflow gates `tag == plugin.json == newest CHANGELOG heading` and publishes the CHANGELOG section as the release body.

## [0.2.1] — 2026-08-30

### Fixed
- **A correct `<repete-done>` claim could be invisible to the engine, and the loop would spin forever.** The hook read the sentinel from the *last assistant entry* in the transcript, but the harness appends one entry per content block plus bookkeeping rows — so a turn that claimed done and then made a tool call (or was simply followed by attachment/mode records) ended on a `tool_use`-only entry whose text is empty. The claim was neither honored nor counted as a mismatch: no teardown, no `stale_count` bump, no feedback to the agent, no yield to the human. Reproduced on a real `autonomous: true` run for three consecutive Stops with a byte-identical goal string. Sentinel extraction now reads the last *text-bearing* main-thread assistant entry of the **current turn**, bounded by the last real user message (`tool_result` rows are `role:user` too and deliberately do not start a turn) — so a spent sentinel from an earlier turn can never be re-fired at an already-approved checkpoint. Worst case is still an empty read, which keeps the loop iterating within budgets.
- **`set_fm` mangled backslashes in frontmatter values.** Values travelled through `awk -v`, which runs them through awk's escape processing. Safe for everything written today (statuses, numbers, UUID session ids), lossy the day a free-text value carries a `\`. Values now travel via `ENVIRON`, byte-for-byte.
- **`set_fm` silently dropped writes to a state file with no closing `---`.** The append-missing-key path keyed off the closing fence, so a hand-truncated frontmatter made every append a no-op: the autonomous safety cap never persisted and the hook re-warned on every single Stop. The key is now appended at EOF and the missing fence written after it, so the file becomes parseable again.
- **No-`jq` degradation is no longer silent.** Missing `jq` still fails open (exit 0, Stop passes through), but an *active* loop now gets one hand-built JSON warning naming the cause and the fix, marked by `.repete/.warned-nojq` so it fires once rather than every Stop. A finished loop stays quiet.

### Changed
- **Bare `paused` removed from the status machine.** No writer ever set it and `/repete-continue` had no branch for it — unreachable surface that cost a couplings row and misled readers. Every real pause is a `paused-*` value; a test now locks it out of the hook's early-exit case.
- **Test coverage for three load-bearing behaviors that had none:** the no-`jq` exit path (state left byte-identical, warning fires exactly once), the stranded-`summarizing` cap re-application (`paused-max` on the *same* Stop, iteration not bumped past the cap), and the `transition.md` checkpoint write (verbatim payload, prior content truncated rather than appended).
- **`ck` assertion convention documented.** `jq -r … | grep -q …` can false-FAIL under `pipefail` when `grep -q` exits early and `jq` takes SIGPIPE — dormant on today's small fixtures, a flake waiting on any payload past the pipe buffer. The test header now specifies the `jq -e` predicate form; new assertions use it, existing ones migrate when touched.

## [0.2.0] — 2026-08-17

### Added
- **Stale detection.** A `<repete-done>` claim that failed the mission-goal match used to fall through silently — the agent got zero feedback and re-claimed blindly until a budget rescued the loop. Mismatched claims are now counted (`stale_count`), a rejection note rides the re-inject ("re-read MISSION.md, quote the goal exactly"), and `stale_limit` (default 3, `0` disables, unparseable → 3 — failing toward the human) consecutive mismatches yield the new `paused-stale` status. A plain work turn resets the count, so stage-wise loops don't false-trip. The yield is budget-class: it stops even autonomous loops, and it survives a context-budget crossing (the note rides the handoff re-inject, so the /clear doesn't eat the feedback).
- **Gauntlet mode (opt-in): builder/critic rounds against a reference.** `gauntlet: true` (plus a non-empty `reference:` — a concrete example of "great" — and `bar:` — one line naming what "reached the bar" means; the hook withholds the rules when either is empty) turns iterations into reference-driven improvement rounds. The agent — not the hook — runs the pattern with subagents: `.repete/parts.md` (part · judgeable criterion · status), one builder per part, ONE fresh-context critic per round blind-A/B-ing round N vs N−1 (`git show`, unlabeled) against the reference, verdict to `.repete/critique.md` whose first line rides the next re-inject, the named gap as next round's top priority, and a final integration critic before any done claim. No new exit paths; the sidechain guard already ignores subagent sentinels; default-off is byte-identical (golden-locked).
- **Statusline pause markers.** Paused states render distinct from a healthy running loop: `·ck` (checkpoint), `·ctx` (context), `·max` (iteration cap), `·stale`. Running and transient `summarizing` stay plain.
- **Marketplace manifest + release pipeline.** `.claude-plugin/marketplace.json` so `/plugin marketplace add` works straight from the repo, and a tag-driven release workflow whose gate enforces `tag == plugin.json == newest CHANGELOG heading` and publishes this file's matching section as the release body.

### Fixed
- **Octal numeric values crashed the hook or silently disabled its budgets.** A leading-zero `iteration: 08` made bash arithmetic throw and the script exit non-zero with no decision JSON; leading-zero budgets error-compared false, disabling the very checks meant to stop runaway loops. All numeric frontmatter reads are decimal-normalized (`num10`), with an overflow guard: >18-digit values fall to the safe default instead of wrapping negative (which disabled cap AND backstop simultaneously).
- **The no-escape backstop now covers GATED loops too.** It was scoped to `autonomous: true` only, so a default-mode loop whose agent simply never checkpoints had no mechanical stop at all — 51 consecutive iterations were reproduced in that state. Any active loop with both budgets at 0 now gets a safety `max_iterations: 25` stamped with a one-time warning.
- **First-occurrence sentinel capture mis-judged quoted examples.** A message containing the sentinel syntax as documentation ("it looks like `<repete-done>example</repete-done>`") before the real claim was judged on the example — bumping the stale counter on a correct claim or promoting a scratch checkpoint payload. Sentinels are now captured at their last occurrence.
- **A UTF-8 BOM in the state file silently killed the loop** (hook and statusline both read it as inactive). The BOM is now stripped — and with perl absent from PATH the read degrades to the raw file (pre-hardening behavior) rather than an empty read; `jq` and `perl` are both fail-open optional.
- **Dead resumes.** `/repete-continue` from `paused-context` or `paused-stale` with an already-exhausted iteration cap resumed into an instant `paused-max` with zero work turns; both branches now check the cap before resuming.
- **`/repete` silently overwrote a finished loop's state** — the re-run guard only fired on `active: true`, so a `done`/`cancelled` loop (including the user-authored constitution) was clobbered without confirmation.
- **Catalog corruption from lesson-card fields.** A literal tab in slug/tags shifted every catalog column; a `#` inside tags (GitHub issue references) was eaten by the comment-stripper; the shipped template's own inline comment on the tags line leaked verbatim into every re-inject. Tabs are normalized in every field, bracket-internal `#` is preserved, and only a comment after `]` is stripped.
- **Statusline quote parity and `paused` differentiation** — template-style quoted frontmatter values (`active: "true"`) render instead of blanking the segment, matching the hook's parser.

### Changed
- **Docs hardened to match the code.** The couplings table gained rows (stale keys, gauntlet keys, statusline markers, sentinel spellings) and the landmine list grew (STALE_NOTE init-outside-guard, fm() first-key trap, GAUNTLET_FALLBACK mirror). Release notes, specs, README, skills, and commands were swept for drift by three review rounds; a doc-lock test block now enforces the mechanical half of the couplings table, and a golden-SHA test locks the default re-inject byte-for-byte.
